Un model care rulează în browser

Cursul 1 · AI și programare. Modelul se descarcă o singură dată și rulează local, pe placa ta video — fără server, fără cont, fără cheie API. În dreapta vezi codul care rulează la fiecare apel.

Browserul tău nu are WebGPU activ, deci modelul nu poate rula aici. Încearcă Chrome sau Edge recent (actualizat), pe un calculator cu placă video.
Prima dată durează. Apoi rămâne în cache-ul browserului.
codul apelului

Codul se actualizează la fiecare acțiune din stânga.

Cum funcționează

De la deschiderea paginii până la răspuns, fără server și fără cheie API.

  1. Biblioteca @mlc-ai/web-llm se încarcă dintr-un CDN (import ... from "https://esm.run/@mlc-ai/web-llm").
  2. Modelul (ex. Llama 3.2 1B, comprimat) se descarcă o singură dată și rămâne în cache-ul browserului.
  3. WebGPU rulează modelul pe placa ta video, local — textul tău nu pleacă nicăieri.
  4. Apelul are aceeași formă ca un API conversațional: o listă de mesaje cu roluri, iar răspunsul vine în flux (stream).

Condiții: Chrome/Edge recent, cu WebGPU, servit peste https (sau localhost). Modelele din browser sunt mici, deci mai slabe decât un model mare din cloud.

Exemple de prompt

Mesajul system schimbă tonul și forma răspunsului. Încearcă:

  • „Ești un profesor de informatică. Răspunzi pe scurt, în română, cu un exemplu simplu.”
  • „Explică totul ca pentru un copil de 10 ani, fără termeni tehnici.”
  • „Răspunde doar cu cod Python comentat, fără text în plus.”
  • „Ești un examinator exigent. Pui o întrebare de verificare după fiecare răspuns.”

Întrebări user de încercat:

  • „Ce este căutarea binară?”
  • „Scrie o funcție Python care verifică dacă un număr este prim.”
  • „Dă-mi un exemplu concret cu numere.” (ca a doua tură — folosește istoricul)
